#Blood Donation WebX

Connecting Blood Donors with People in Need

#About the Project

Blood Donation WebX is a web-based application designed to connect blood donors with people who need blood. It provides a simple platform for donor registration and blood requests.

# Objective

The main objective is to make blood donation information accessible and help people find potential blood donors easily.

# Features

- Donor Registration
- Blood Request Form
- Blood Group Information
- Donor Details
- Simple and User-Friendly Interface

# Technologies Used

- HTML – Website Structure
- CSS – Website Styling
- JavaScript – Website Functionality

#Project Structure

- "index.html" – Home Page
- "register.html" – Donor Registration
- "request.html" – Blood Request Page
- "lastp.html" – Additional Web Page
- "lastpage.html" – Additional Web Page

# How to Run

1. Download or clone this repository.
2. Open the project folder.
3. Open "index.html" in your browser.
4. Explore the website.
